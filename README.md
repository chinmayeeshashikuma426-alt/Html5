# Accessible Semantic HTML5 Portfolio

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Accessible contact form

## Accessibility features
- Semantic HTML5 landmarks: `header`, `nav`, `main`, `section`, `article`, `footer`
- One clear `h1` per page and logical heading hierarchy
- Skip-to-content link
- Keyboard-friendly navigation and visible focus indicators
- Descriptive labels and required states for form controls
- Accessible navigation with `aria-label` and `aria-current`
- Reduced-motion support
- Responsive layout
- SEO-friendly title, description, author and robots meta tags
- Good color contrast and no color-only instructions

## Run
Open `index.html` in a browser, or serve the folder with a local web server.

## Lighthouse
Run Chrome DevTools → Lighthouse → Accessibility + SEO. The project is designed for high scores, but Lighthouse results can vary by browser/version and hosting environment. A perfect 100 cannot be guaranteed without testing the deployed site.
